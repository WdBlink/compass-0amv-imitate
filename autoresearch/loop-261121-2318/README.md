本轮目标不变：64 个官方交易日的日涨跌幅 MAE 严格低于 0.01 个百分点。起点是第一轮
交付的 0.011320464 个百分点。**目标仍未达到**：终点为 **0.011278744 个百分点**，
还差 0.001278744 个百分点。

小幅改进、一份把残差定位到具体交易日的诊断、以及一份把已排除机制写清楚的台账，

的机制，而不是拟合出来的十进制数。

## 残差在哪里

`scripts/diagnose.py` 把模型点位与官方点位之差（gap）逐日拆开。误差不是弥散的：

- 64 天里 50 天单日绝对误差已经低于 0.01 个百分点；
- 8-03、8-31、10-23 三天贡献了全部绝对误差的 36%；
- 把这三天去掉，其余 61 天的 MAE 是 0.007183 个百分点。

这三天的形态一致：模型点位在当天跳高一次，随后按筹码衰减率回落。官方点位本身
与模型点位之比一直稳定在 0.9997 附近（变异系数 0.00024），也就是说**水平是对的，
只有这几天的日内路径不对**。

## 已排除的机制

`loop-results.tsv` 记录了 30 个候选。以下方向被数据否定，不再重复：

| 方向 | 结果 |
|---|---|
| 官方用成交额口径换手率（额／流通市值） | 0.062749 |
| 官方用自由流通股本做换手分母 | 0.312490 |
| 官方剔除停牌股（全程剔除／仅首日剔除） | 0.024993／0.022160 |
| 官方用滞后一日的流通股本计价 | 0.070667 |
| 官方用复权价 | 0.014800 |
| 官方用自由流通股本计价 | 0.157415 |
| 无存活项的筹码递推（survival=off） | 0.267733 |
| 按个股换手率缩放衰减系数 | 0.305362 |
| 压平活筹比例的横截面离散度（换手下限、f 上限） | 0.011513／0.012041 |
| 换手冲击衰减 2% | 0.018543 |
| 更长的行情预热（多接 320 个交易日） | 0.011283，可用但需要额外历史 |
| 新股上市首日按 q 入池 / 按稳态入池 | 与官方首日点位差 ±30 亿元以内，现处理正确 |
| 官方点位含北交所或剔除 302 创业板 | 0.011511 |
| 面板数据自检：收盘价越界、换手率与量／股本不一致、除权除息 | 64 日窗口内无影响量级的异常 |

其中「停牌股」一项值得单独说明：8-31 停牌的 688432.SH 带 238.8 亿元活筹市值，
与当日水位跳升的量级相当，但官方点位在 9-23 复牌时并未出现对应的回落，缺口按筹码
衰减率一路缩小，因此**官方在停牌期间保留该股市值**这一处理已被排除。
