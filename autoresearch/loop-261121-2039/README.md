## 实验与选择

`loop-results.tsv` 的每个候选先提交到独立本地实验副本，随后在相同的 64 个日期上评分。`commit` 列指向打分时的候选树，全部版本保存在 `candidates.bundle`。基线之后有 7 次保留、18 次弃用。比较条件为全段和前半段 MAE 下降，同时后半段 MAE 和官方点位与模型点位之比的变异系数均不升高。两个半段都参与了取舍，不能用来估算盲测成绩。

第 19 轮在新股上市首日混用收盘价与成交均价，整段 MAE 为 0.011136，但后半段从 0.007796 上升至 0.008131，故未选入。第 25 轮把中位数初始窗口延长至 40 日，全段 0.011317，后半段和点位比例稳定性也略差于第 24 轮。同期探索还检查了停复牌、风险警示、解禁调整、盘后成交量、较长行情预热及筹码寿命，均未验证出满足全段目标的规则。没有按日期或证券代码回填官方残差。

## 复算

从项目根目录运行。第一条命令计算当前正式规格的全精度指标，第二条重放保留及弃用过的所有实验版本。

```sh
python3 research/autoresearch/evaluate.py
python3 autoresearch/loop-261121-2039/replay.py
```

- 用户交接文件指向的原始 64 日读数与项目评分副本匹配，评分副本 SHA-256 为 `176e0335f5c062fa3d93951ccb15afcaa83641f0b55da693d8c9fa90d47c75ea`。起始 Git 版本为 `c8ccbb239e32d20b0612e833224a45fd36f471a5`。
- 重放使用本地冻结行情以及 `~/Data/datasets/derived/compass-0amv/autoresearch-261121-2039/` 中带有代码轴与校验值的市场补充输入。`blocks.npz` 来自 Tushare `block_trade` 的逐股逐日成交明细，单位换算为股。`lifecycle.npz` 取自同一冻结行情中的 `stock_basic`。可以用 `--extra` 指定另一份匹配的输入。
- `replay.py` 在临时克隆中检出各候选，重算总 MAE、两段 MAE 与点位比值变异系数，容差为 `1e-9`。实验中的初值使用完整预热段，正式实现的稳健初值在最初 20 日逐日递增可见窗口，两种实现对计分窗口给出同样的日幅。该行情中所有有报价的股票行都有有效流通股本。对于其他来源的有价缺股本行，正式接口当日按零市值计，仍可用已披露换手更新筹码；候选脚本将这类行视作缺报价。
