# 官方显示精度核验

当前没有完成官方算法复刻。本目录保存 64 个交易日的 App 显示读数和可重跑的逐日核验，不把近似值改称官方值。

## 样本与输入

`official.csv` 是 2026-07-27 至 2026-10-30 的收盘值和日涨跌幅。读数来自用户授权操作的指南针 App 历史日线“收”和“涨幅”字段，由 AI 逐图核对，尚待人工验收。收盘显示精度为 0.1，涨幅为 0.01 个百分点。这些是软件显示读数，不是官方提供的算法规范或未舍入数据。

64 日均已用于前面的研究，不能再称为盲测或新样本外验证。涨幅基本是收盘序列的派生信息，不能把两列当成 128 个独立公式约束。

`calendar.csv` 包含样本交易日和首日前一个交易日。两个 `predictions_*.csv` 各有 65 行未舍入计算值，供核验器独立推导涨幅。预测在 2023-01-03 起的 925 行市场数据上计算后截取，不在首个评分日重新初始化，也不以官方值拟合比例。

| 文件 | 公式 |
|---|---|
| `predictions_amount_only.csv` | `SMA(SH_amount + SZ_amount, 10, 1) / 1e7` |
| `predictions_sse_price_adjusted.csv` | `SMA(SH_amount, 10, 1) * SH_close / MA(REF(SH_close, 1), 5) / 1e7` |

输入金额来自 Tushare `index_daily` 的 `000001.SH` 和 `399106.SZ`，由千元转换为元。两市指数并不自动等于指南针内部成分股范围。第二个公式是原监控使用的价格调整代理，不是本仓库的默认公式。

公开包不包含设备截图、原始供应商响应、运行主机记录或凭据。`manifest.json` 记录本地源数据哈希与公开文件哈希。外部审阅者可复算本包预测与标签之间的差异，但不能仅凭哈希独立确认截图转录。原始证据保留本地。这里的 64 日事实读数不代表官方授权或认可本项目。

## 运行逐日核验

本次运行结果如下。事件不一致包含漏触发和错误触发，未把官方显示值代入规则的结果称为 App 官方信号。

| 基线 | 收盘显示一致 | 涨幅显示一致 | 单日触发条件不一致 |
|---|---:|---:|---:|
| 全市场成交额平滑 | 0/64 | 0/64 | 16/64 |
| 上证成交额价格修正 | 0/64 | 0/64 | 10/64 |

逐日证据在 `amount_only_report.json` 和 `sse_price_adjusted_report.json`。它们是预期失败的负对照，不是已通过的复刻结果。10 月 30 日的官方值为 `133970.9`、`-2.17%`，原上证代理为约 `74210.038`、`-1.30318%`。两者当日都没有越过 `-2.3%`，但这不消除其他日期的触发错误。

在仓库根目录执行。核验器只使用 Python 标准库。

```bash
python tools/verify_exact_parity.py \
  --official research/exact_parity_20261030/official.csv \
  --predictions research/exact_parity_20261030/predictions_amount_only.csv \
  --calendar research/exact_parity_20261030/calendar.csv \
  --output /tmp/amount_only_parity.json
```

将预测文件替换为 `predictions_sse_price_adjusted.csv` 可复核另一基线。两次核验的预期退出码均为 `1`，表示不满足逐日一致要求。退出码 `0` 只表示这个已曝光样本的显示数值和可判定触发条件一致，不证明找到了官方算法。输入无效返回 `2`。

核验器按以下规则判断。

- 收盘误差必须小于 0.05，涨幅误差必须小于 0.005 个百分点。每一天都要满足，不能以平均值抵消失败。
- 恰好位于半个显示单位的结果标为舍入歧义，不推定官方使用哪种半值舍入规则。
- 涨幅由相邻预测收盘独立计算。预测文件不得传入自报涨幅，也不能缺少首日前值或中间交易日。
- 单日触发条件为未舍入涨幅 `>= +4%` 或 `<= -2.3%`。官方只显示 `+4.00%` 或 `-2.30%` 时，内部值跨越阈值的方向无法确定，必须标记歧义。
- 触发条件是本项目给定的交易规则，不是从 App 读取的官方多空状态。白黄线、持仓状态和旧的两日合计规则不在本核验器的范围内。

即便所有显示值通过，报告中的 `official_formula_replication` 仍为 `not_established`。这是有意区分有限样本一致和完整算法复原。查表、逐日补残差、用官方前值重置状态，均不能作为公式复刻的证据。


市场文件须包含 `date,sh_close,sh_amount,sz_amount,amount`。金额单位为元，且 `amount=sh_amount+sz_amount`。本次来源窗口为 2023-01-03 至 2026-10-30。没有这份源文件时仍可复算已发布预测的核验结果，但不能宣称独立重建了市场输入。

导出器只用官方日期选择评分窗口，官方数值不参与预测。标签污染与未来尾部污染测试检查这一约束。导出目标必须不存在，防止覆盖冻结证据。

## 为什么目前不能宣称完全复刻

仅调平滑参数与固定缩放倍数的路线已有反证。考虑任何正平滑系数的公式 `Y_t=(1-alpha_t)*Y_(t-1)+alpha_t*c*x_t`，其中 `x_t=当日两市成交额/1e7`，`c` 固定且为正。`Y` 的涨跌方向必然等于 `c*x_t-Y_(t-1)` 的符号。

| 日期 | `x_t` | 前日官方点位 | 当日官方点位 |
|---|---:|---:|---:|
| 2026-08-12 | 215242.310981535 | 210839.2 | 210962.0 |
| 2026-08-13 | 255091.673935884 | 210962.0 | 208572.3 |

即使给所有点位留出 ±0.05 的舍入空间，8 月 12 日上涨仍要求 `c > 0.9795432368`，8 月 13 日下跌仍要求 `c < 0.8270048440`。这两个条件不能同时满足。`tests/test_exact_export.py` 用 Decimal 复核这项反证。它排除固定比例的成交额正系数一阶平滑，不排除含价格、动态比例或其他状态的模型。

[指南针的官方说明](https://www.compass.cn/shownews.php?nid=29998817)给出活跃筹码和资金数量的含义，并教用户在已经生成的 0AMV 图上另加 5 日成本均线。这是指标用法，不是 0AMV 的生成公式。

[官方 CYS 说明](https://aweb.compass.cn/article/app/news.php?newsid=33825230)给出 `CYS=(Close-CYC)/CYC*100%`。这只能用于核验成本均线与乖离率的关系，不能反推出 0AMV。[官方经典指标帮助](https://www.compass.cn/help/boyi/4-1-2.html)也未给出足以计算 0AMV 的完整递推。

本轮核查未找到完整官方计算规范。这不等于证明它永远不可取得。仍须确认历史成分范围、输入字段、活筹识别及递推、初始化、停牌和除权处理、内部精度及历史修订规则。只有两个指数的成交额和价格，不能确认这些信息。

下一步的关键证据是官方计算规范与同口径输入，或者可授权取得的官方原始导出，再增加未参与开发、覆盖上涨和阈值边界的独立窗口。接入官方数据可解决“读取官方结果”，但不能冒充“独立复现计算公式”。在这些缺口解决前，保留近似代理的未校准状态。
