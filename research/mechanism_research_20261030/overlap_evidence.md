# 能从累计成交量认出哪些筹码被反复交易吗？

不能。每天的日线给出成交股数，不告诉我们今天成交的是不是昨天的那批股。这是对一个候选定义的排除实验，不是 0AMV 的点值预测。

假设流通盘为固定的 `F` 股，每一天记录的 `V_s` 股互不重复，近 `N` 个市场交易日内至少交易过一次的不同股份算作活筹。允许每天反复交易同一批，也允许每天更换。集合并集直接给出：

```text
max(V_s) ≤ 至少成交过一次的不同股数 ≤ min(F, sum(V_s))
```

若每天都从同一编号顺序取前 `V_s` 股，就能达到左端；若尽量选尚未交易过的股份，能达到右端。以当日未复权收盘价计值，假设一显示单位等于一亿元、无其他除数。每只股票的下界向下取整、已覆盖股票的上界向上取整后再汇总。遗漏股票的贡献非负，因而已覆盖下界仍是市场下界；**只针对已覆盖股票的上界不是市场上界**。沪市普通 A 股及沪深普通 A 股分别测试，使用与[等比例留存的现价对照](active_value_bounds.md)相同的逐日合格股票。

在 2026-07-27 至 2026-10-30 的 64 个已曝光开发日，事前冻结了 5、13、34 个交易日三个回看长度。仅当下界严格大于官方一位小数显示值加 0.05，才排除这组假设：

| 普通 A 股范围 | 回看 | 等比例记账被排除 | 任意跨日重叠被下界排除 |
| --- | ---: | ---: | ---: |
| 仅沪市 | 5 / 13 / 34 日 | 分别 0 / 0 / 0 天 | 分别 0 / 0 / 0 天 |
| 沪深 | 5 日 | 0 天 | 0 天 |
| 沪深 | 13 日 | 5 天 | 0 天 |
| 沪深 | 34 日 | 64 天 | 0 天 |

例如 10 月 30 日，沪深 34 日组合的同一批 3,904 只合格股票，等比例记账的金额为 186,990.11，高于官方收盘 133,970.9；允许跨日重复成交时，数学下界为 21,830.12，不能用它排除该收盘。**0 天被排除不是 64 天匹配，更不是误差为零。** 这个实验既不确定实际成交重叠，也没构造出一条同时解释所有官方日值的可行路径；未计算日涨跌幅或多空触发。

[TuShare 日线数据字典](https://tushare.pro/document/2?doc_id=27)定义的是交易手数，另有盘后字段，没有提供逐份股份身份。上述“日内无重复”是模型前提，并非日线已经观测到的事实。若同一份筹码能在一日内重复计量，连用单日成交股数作下界的推导都不成立。[指南针讲座](https://aweb.compass.cn/article/app/news.php?newsid=33838916)谈到活筹流通盘和活筹换手率，但不能据此确定市场汇总公式。更有辨识力的下一步是以独立个股的官方活筹换手率约束活筹流通盘，而不是调整指数代理的比例。

[预测代码](overlap_bound.py)只需独立市场快照。384 个日×市场×窗口的下界输出在比较官方文件前已关闭，CSV SHA-256 为 `383a20cca68473c04f2d24f48c31edda47cad24640d7762410e6bbf72b68fe69`；输入市场清单与开发日历沿用现价对照。没有采集或查看新的盲窗。
