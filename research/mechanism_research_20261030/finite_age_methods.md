# 有限年龄库存单股探针

本模块实现研究计划 P2 的候选 A。它不是指南针官方公式，也没有建立 CYF、活筹流通盘和 0AMV 的等价关系。工程测试不证明官方结果复刻。

## 数据边界

输入是一只股票的完整有序序列和独立声明的市场交易日历。`StockDay` 包含日期、股票标识、未复权 OHLC、成交股数、成交额、流通股数和复权因子。股数单位为股，金额单位为元。数值接受整数、十进制字符串、`Decimal` 和 `Fraction`，拒绝二进制浮点数及布尔值。

模块拒绝缺行、重复或错序日期、混合股票、非法数值、价格区间外的 OHLC 或成交均价、流通股变化和复权因子变化。没有停牌填充或企业行动处理。显式零成交行仍消耗一个声明的市场日。零成交必须对应零成交额。

调用者负责证明日历来自独立输入。纯函数无法判断调用者是否把缺失交易日从声明日历中一起删除。私有实验独立核对冻结交易所日历及原始请求清单，不依赖正在修复的快照加载器。

## 候选数学定义

令 `q[t] = volume[t] / float_shares[t]`，要求 `0 <= q[t] < 1`。候选分母是传统流通股数。[官方无极版说明第七节](https://www.compass.cn/help/wuji/4-1-3.html)另有剔除长期不交易筹码的活筹流通盘定义，不能据此把 `float_share` 或 `free_share` 当作官方活筹分母。[官方经典指标说明](https://qy.compass.cn/html/protocol/funcintro.php?ver=1.0)列出 CYC 的 5、13、34 日及无穷成本概念，但没有给出本候选的退出权重算法。

长度 N 的窗口使用 N 个声明市场日。当前窗口内第 s 日成交的存活权重为

`w[s,t] = q[s] * product(1 - q[j], j=s+1..t)`。

有限年龄库存比例为

`f[t,N] = sum(w[s,t], s=t-N+1..t) = 1 - product(1-q[s], s=t-N+1..t)`。

`CYF_candidate = 100*f`。成交均价 `p[s] = amount[s]/volume[s]`。成本候选为 `CYC_candidate = sum(p[s]*w[s,t])/f`。零成交行不产生权重。完整窗口的 `f=0` 时成本无法识别，返回 `None`，不代入现价。窗口不足 N 日时比例与成本均为 `None`，`available=False`。默认周期 5、13、34 来自既有假设，没有用标签拟合。

计算使用 `Fraction`，不依赖浮点舍入或 `Decimal` 精度上下文。结果包含 `initial_survival=product(1-q)`，表示从序列开始之前留下的未知库存仍存活的比例。这只诊断无限期成本的初态不确定性，不生成未知成本，不读取官方前值。有限窗完整之后，不需要窗口以前的成交成本。

私有实验另列 Poisson 比例 `100*(1-exp(-sum(q)))` 和普通窗口成交均价。Poisson 是双精度诊断，不是精确测量评分器。有限均匀退出中 `1-q <= exp(-q)`，因此其比例不小于 Poisson 比例。有限库存成本按退出权重计算，普通窗口成交均价不衰减较早交易，两者可分辨不同机制。后续必须先冻结显示精度及舍入契约，才可对官方观察作区间判定。

## 实验范围与限制

私有试验只读取获授权的冻结市场输入，不读取任何官方标签。选择截至 2026-10-30 的最后 40 个完整市场日，并在全部 40 日检查每只候选的边界。高换手、低换手和脉冲后转冷样本均按事先声明的确定性规则选择。该选择使用截止日已知历史，不是逐日时间点交易回测，也不代表全市场。

计算器不聚合多股，不读取文件或网络，不重置官方状态。没有冻结 0AMV 公式，没有执行 64 日官方核验，没有取得两个新 20 日盲测窗口。开发输出仍待独立审查和人工确认。

P3 合成测试用价格 1、2、3 和各 100 股流通盘构造两组市场。每天成交股数分别为 `10,10,10` 和 `15,0,15`，持续 13 日。两组每天总成交股数均为 30，总成交额均为 60，总流通市值均为 600。但是逐股有限年龄库存的现价总值分别为 `600*(1-0.9^13)` 和 `400*(1-0.85^13)`，并不相等。该反例证明，仅有这些市场总量不能唯一识别此候选的逐股库存聚合值。它不证明官方采用该候选。
